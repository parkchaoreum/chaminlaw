## 2. 올리기 전에 반드시 채워야 할 것

### 2-1. 카카오톡 채널 주소 — 연결 완료

모든 페이지(16곳)의 카카오톡 버튼이 아래 주소로 연결되어 있습니다.

```
http://pf.kakao.com/_xhEenX
```

**`/chat` 을 붙이지 않은 이유:** `pf.kakao.com/_xhEenX/chat` 은 카카오
로그인 화면부터 띄우고, 로그인하지 않은 방문자에게는 "비공개 또는 삭제된
채널" 오류가 납니다. `/chat` 없는 채널 홈은 로그인 없이 바로 열리고,
그 안에 **채팅으로 문의하기** 버튼이 있어 결과적으로 더 잘 연결됩니다.
채널 홈에는 사무실 사진·주소·영업시간·길찾기·전화하기도 함께 나옵니다.

`http://` 는 카카오가 자동으로 `https://` 로 넘겨주므로 어느 쪽이든
동작합니다.

채널 주소가 바뀌면 5개 HTML 파일에서 `pf.kakao.com` 을 찾아 바꾸면 됩니다.

### 2-2. 변호사 학력·경력 — 반영 완료

`attorneys.html` 에 두 분 약력이 모두 들어가 있습니다.

- **박차오름** — 학력 3 / 경력 3 / 위촉·활동 7
- **이민규** — 학력 3 / 경력 5

주신 목록에 자격증 항목이 없어 `자격` 묶음은 두지 않았습니다.
나중에 추가할 항목이 생기면 아래 형식을 그대로 복사해 쓰시면 됩니다.

```html
<li><b>現 법률사무소 차민</b> 대표변호사</li>
<li>원광대학교 법학전문대학원 졸업 <b>수석입학</b></li>
```

`<b>` 로 감싼 부분이 진하게 강조됩니다.

**아직 안 들어간 것:** 사무실에 걸린 표창 중 경찰청장·경찰서장 표창,
국방부장관 임관사령장 등은 목록에 없어 넣지 않았습니다. 넣기를 원하시면
정확한 명칭과 연도를 알려주세요.

### 2-3. 도메인 — 설정 완료

**`https://www.chaminlaw.com`** 기준으로 모두 반영해 두었습니다.
(canonical 5곳, og:url·og:image 10곳, 구조화 데이터 3곳, robots.txt 1곳,
sitemap.xml 5곳 — 총 24곳)

이메일 주소(`chaoreum@chaminlaw.com`, `mingyu@chaminlaw.com`)는 `www` 가
붙지 않는 것이 정상이므로 그대로 두었습니다.

#### 호스팅에서 꼭 해둘 것: `chaminlaw.com` → `www.chaminlaw.com` 넘김

도메인은 `www` 없이도 접속이 됩니다. 두 주소가 같은 내용을 보여주면
검색엔진이 별개 사이트로 보고 검색 순위가 나뉩니다. 그래서 `www` 없는 주소로
들어온 사람을 `www` 주소로 **자동으로 넘겨주는 설정(301 리다이렉트)** 을
해두어야 합니다.

호스팅 관리자 페이지에서 보통 "도메인 연결" 또는 "리다이렉트" 메뉴에 있습니다.
Netlify·Vercel은 기본 도메인을 `www.chaminlaw.com` 으로 지정하면 자동으로
처리됩니다.

그리고 **https** 로 접속되도록 SSL 인증서를 켜두세요. 요즘 호스팅은 대부분
무료로 제공하며, 없으면 브라우저가 "안전하지 않음" 이라고 표시합니다.
법률사무소 사이트에서는 특히 좋지 않습니다.

## 4. 지도 넣기

`location.html` 에 지도 자리(`<div class="mapframe reveal"></div>`)를 비워
두었습니다. 비어 있는 동안에는 아무것도 표시되지 않습니다.

네이버 또는 카카오에 사업장을 등록한 뒤 **지도 퍼가기** 로 받은 `<iframe>`
코드를 이 div 안에 그대로 붙여넣으면 지도가 나타납니다. 크기는 자동으로 맞습니다.

- 네이버: 네이버 스마트플레이스 등록 → 지도에서 업체 검색 → 공유 → 퍼가기
- 카카오: 카카오맵 장소 등록 → 지도에서 검색 → 공유 → 지도 퍼가기

구글 지도 임베드는 한국 주소 데이터가 부실해서 쓰지 않았습니다. 대신 지도
앱으로 바로 여는 버튼(네이버·카카오·구글)을 넣었고, 이건 등록 없이도 동작합니다.

## 5. 올리는 방법

이 폴더 안의 내용물을 웹호스팅의 최상위 폴더에 그대로 올리면 됩니다.

- **카페24 / 가비아 등 일반 웹호스팅**: FTP로 `public_html` 또는 `www` 안에 업로드
- **Netlify / Vercel**: 이 폴더를 드래그해서 올리면 끝
- **Github Pages**: 저장소에 올리고 Pages 활성화

주의: 폴더 자체가 아니라 **폴더 안의 파일들**을 올려야 `index.html` 이
첫 화면이 됩니다.

### 미리보기

`index.html` 을 더블클릭하면 바로 열립니다. 다만 브라우저 보안 정책 때문에
일부 기능(주소 복사 등)은 실제 서버에 올린 뒤에야 정상 동작합니다.

## 6. 디자인 메모

- **색**: 명함에서 그대로 가져왔습니다. 차콜 `#17191D` 바탕에 샴페인 골드
  `#C6A667`, 로고의 파랑 `#1B5E9E` 는 심볼에만 씁니다.
- **글꼴**: Pretendard(본문·제목), Cormorant Garamond(숫자·영문 라벨).
  둘 다 무료이고 CDN에서 불러옵니다.
- **시그니처**: 홈 첫 화면의 `박[차]오름 + 이[민]규 → 차민`. 사무소 이름의
  유래를 그대로 화면에 옮긴 것이고, 이 사이트에서 가장 눈에 띄는 요소는
  여기 하나로 몰아두었습니다. 나머지는 조용하게 유지했습니다.
- **로고**: 원본 JPG는 흰 배경이라 어두운 헤더에 못 씁니다. 배경을 투명으로
  빼고, 어두운 배경용 역상 버전을 따로 만들어 두었습니다. 국문 워드마크는
  오프화이트, 영문은 회색, 심볼은 브랜드 파랑을 유지해 원본의 위계를
  그대로 살렸습니다.
